# 现场演示脚本（验收用）

> 交付包默认空库（`data/features.json` 里 `objects` 为空）。**第一步是在空库上现场录入一个新物体**——这正好对应选题书现场演示的第一项；之后依次是正常识别、未知判断、语音交互、重启复现、加分项（摄像头），最后抽讲代码。
> 报告样本 41 张图放在 `samples/`（`known/` 25、`test/` 10、`unknown/` 6），**仅用于报告复现，不自动入库**，启动流程不读取它们。
> 阈值 `0.8124` 是**课程 5 物体样本上校准的参考值**，不是通用常数；现场录入的物体若与课程样本差异较大，用 `tools/calibrate.py` 重新校准。`data/realtime.json` 的 0.75 / 0.90 是**未在标准流程下校准的占位值**，不作结论。
> 实机结论按小组电脑上的实际演示口述如实记录：语音识别、语音播报、标注图中文均已实机确认可用；摄像头实时页**已实机测试，但存在手部干扰这一已知局限**（见 §7），不写"全部通过"。

## 0. 开场前检查（5 分钟）

```bash
python --version                 # ≥ 3.10
python -c "import torch, gradio; print(torch.__version__, gradio.__version__)"
python tools/demo_cli.py stats
```

预期 `stats` 输出：**物体数 0、特征向量 0**（交付包是空库，这正是现场录入的起点）。

逐项确认（任一项不过就现场换方案，不硬撑）：

- [ ] `~/.cache/torch/hub/checkpoints/resnet18-f37072fd.pth` 已存在，首跑不下载
- [ ] `~/.rn18/.env` 有百度 Key，`BAIDU_ASR_DEV_PID=80001`
- [ ] 联网正常（Edge TTS 要用），断网时提前说明播报降级
- [ ] 麦克风有输入电平，摄像头没被别的程序占用
- [ ] 中文字体正常（Windows 自带微软雅黑；Linux 要有 Noto CJK）

## 1. 第一步：在空库上现场录入一个新物体（必做项①）

```bash
python app.py
# 浏览器打开 http://127.0.0.1:7860
```

预期：三个 Tab ——「1 · 多图录入」「2 · 单图识别」「3 · 实时识别」，Tab1 表格为空。

- 拿一个**现场没录入过**的小物体，从 5 个不同角度各拍一张。
- Tab1 输入物体名称 → 上传这 **≥5 张**图片 → 点「录入并保存」。
- 预期：状态栏「已录入「X」：新增 5 条特征」，下方表格出现该物体与条数；`python tools/demo_cli.py stats` 显示物体数 1、向量 5 条。

等价的命令行入口（界面无法无头驱动时用它演示同一入库流程）：

```bash
python tools/demo_cli.py add --name 现场新物体 --dir my_object
python tools/demo_cli.py stats
```

坑：没填名称 → 提示先输入；重复上传同一张 → 像素摘要去重，不虚增条数；只录入没点「录入并保存」→ 重启后为空。

> 想快速复现课程数据，可把 `samples/known/water_cup`（5 张）当作录入来源，但**现场演示请以新物体为主**，这样才对得上选题书"现场录入"的第一项。

---

## 2. 必做项②：输入图片返回最相似名称与相似度

- 换一个角度、或换一段距离，**另拍一张**作测试图（不要用刚才那 5 张注册图）。
- Tab2 上传 → 点「开始识别」。
- 预期：显示刚录入的名称 + 相似度（含百分比）、绿框标注图、前 3 个近邻表，判定为已知物体。

```bash
python tools/demo_cli.py recognize --image my_object_test.jpg --top-k 3
```

坑：特征库为空 → 提示先录入；分数偏低 → 先确认没拿错物体，再考虑光线/距离。若现场物体与课程样本差异较大导致分数整体偏低，用 `tools/calibrate.py` 以你自己的测试图重新校准阈值，不要硬套 0.8124。

---

## 3. 必做项③：相似度低判未知物体

- 拿一个**没录入**的东西（现场随手取，或 `samples/unknown/` 里的乌龙茶、充电头、剪刀）上传 Tab2。
- 点「开始识别」。
- 预期：红色标注框 + 「未知物体」，最高相似度低于当前阈值。

课程样本复跑时的参考数值（仅用于报告复现，见 `docs/evidence/p6b_verification.txt`）：

| 未知物 | 最近邻（库里最像的） | 最高分 | 判定 |
|---|---|---|---|
| 充电头1 | power_bank | 0.7421 | 未知物体 |
| 乌龙茶1 | water_cup | 0.6893 | 未知物体 |
| 剪刀2 | mouse | 0.6282 | 未知物体 |

阈值来源：课程测试图最低 0.8828、未知样本最高 0.7421，取中点 0.8124，两侧各留 0.070；它是课程样本上的参考值，不是通用常数。

坑：如果现场拍的新图分数异常低，先确认是否拿错物体，再考虑光线/距离。

## 4. 必做项④：语音说出物体名称

- Tab1 填好物体名后，点「语音识别名称」→ 对着麦克风说名称 → 名称框回填。
- 预期：名称框出现带标点的文本，可键盘改后再「录入并保存」。实机确认可用，真人说话回填名称正常。
- 若未配 Key：按钮置灰并提示用键盘，`asr()` 不调用，不崩。

坑：网络不通 → 百度接口报错，界面只显示错误码文案；没麦克风 → 直接键盘输入并说明语音链路已单独验证。

---

## 5. 必做项⑤：语音播报识别结果

- 回到 Tab2，再识别一次已知物体。
- 预期：识别完成后**自动朗读**「识别结果：X」，同时画面出结果。实机确认可用，中文正常，播报当次识别结果。
- 断网时预期：显示「语音播报不可用，请检查网络」，识别结果照常显示——这是降级，不是故障。

坑：第一次合成会慢 1–2 秒（要走网络），别急着点第二下；音量为 0 会被误认为没播。

---

## 6. 必做项⑥：简单界面 + 重启后特征库仍在

- Tab1 点「刷新特征库」：从磁盘重读，表格不变 → 内存与磁盘一致。
- **关掉 `python app.py`，重新启动**，再打开 Tab1。
- 预期：刚录入的那个物体、5 条向量都还在，无需重新录入。

```bash
python tools/demo_cli.py stats    # 新进程从磁盘重新加载，物体与条数仍在
```

坑：不点「录入并保存」就退出 → 重启后为空。

## 7. 加分项：摄像头实时识别（已测，但存在已知局限）

摄像头实时页（Tab3）**已在小组电脑上实机测试**，但发现**手部干扰**：手举物体时常被当成目标，属已知局限。

- 根因：整帧 ResNet18 特征没有"目标区域"的概念，阈值只管分数高低，无法区分贡献来自手还是物体；界面上的标注框是**整图状态框，不是目标检测框**。选题书不要求定位，本项目未引入检测模型，也没有实现手部剔除。
- 使用建议（演示时减轻干扰，不是已实现的功能）：物体居中、尽量占满画面；手退出画面后再判定；等连续多帧结果稳定后再采信。

**持续识别**：Tab3 打开摄像头 → 对准已录入物体；画面叠加名称与相似度，未知显示「未知物体」；播报按「结果变化 + 4 秒冷却」。首帧常黑/过曝，代码会丢前 2 帧预热。

**教学式录入**：点「教它」→ 识别与 TTS 暂停 → 按 ≥0.2 s 间隔抓 5 帧 → 录音说名称 → ASR 回填 → 确认入库（条数 +5）→ 退出教学态恢复识别与 TTS。教学抓的 5 帧算**注册图**，不能拿来当测试图。

> 实时阈值 `threshold_realtime`、`threshold_bg`、`bg_crop_margin` 仍未在标准流程下校准（占位），`tools/realtime_check.py` 的真机校准未验证。此处不声称"实时全部通过"，也不写未测的误报/恢复秒数。

## 8. 抽讲代码（教师随机抽问）

按 [关键函数讲解卡 docs/function_cards.md](../docs/function_cards.md) 准备，重点能当场讲清：

- `core/features.py` 为什么去掉 `fc` 取 512 维、为什么 L2 归一化；
- `core/library.py` 的 `load_library` / `save_library` 如何实现"重启后仍在"（原子写入 + 启动加载），以及交付包为什么默认是空库；
- `core/recognize.py` 的余弦检索与"最高相似度 < 阈值判未知"；
- `core/pipeline.py` 的 `recognize_stream` 背景门与中心裁剪为什么不引入检测模型；
- 阈值 0.8124 的来源（课程样本两条分布取中点）与"参考值"口径。
