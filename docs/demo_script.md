```bash
# 确认 Python 与依赖
python --version          # ≥ 3.10
pip install -r requirements.txt

# 离线权重（无网机器）：把 resnet18-f37072fd.pth 放到
#   ~/.cache/torch/hub/checkpoints/ 或设置 TORCH_HOME
```

坑：首次运行会联网下载约 45 MB 权重；若卡住，先确认权重已就位或网络可用。

## 1. 启动界面

```bash
python app.py
# 浏览器打开 http://127.0.0.1:7860
```

预期：看到 Tab1（多图录入）、Tab2（单图识别）。

---

## 2. 多图录入（必做项：录入并保存特征）

- 在 Tab1 输入物体名称（如「水杯」），上传该物体的 5 张以上图片。
- 点「录入并保存」。
- 预期：状态栏显示"已录入「水杯」：新增 N 条特征"，下方表格出现该物体与条数。

逐个录入 5 个物体，每物体 ≥5 张。

> 名称口径：本仓库已入库的物体名是英文目录名（`power_bank` / `water_cup` / `earphone` / `keyboard` / `mouse`）。现场若直接复用 `data/features.json`，识别结果也显示英文名；若要中文名，按本节用中文名重新录入即可，两种都符合要求，不要一份库里混用。

坑：
- 没填名称 → 提示"请先输入物体名称"。
- 上传同一张图两次 → 按像素摘要去重，不虚增条数。
- 录完看一眼 Tab1 表格，确认 5 物体 × N 条向量都在。

---

## 3. 输入图片返回最相似名称与相似度（必做项）

- 切到 Tab2，上传一张**测试图**（与注册图不同的那 2 张之一）。
- 点「开始识别」。
- 预期：显示物体名（如「水杯」）、相似度（如 0.92）与百分比；标注图绿框 + 名称；下方前 3 个近邻表。

坑：
- 特征库为空 → 提示"请先录入物体"。
- 相似度异常低 → 确认上传的是注册物体之一，且没有拿错图。

---

## 4. 相似度低判未知物体（必做项，当前为占位阈值）

- 上传一张**明显不在库里**的物品或空白图。
- 预期：返回「未知物体」，最高相似度低于阈值（当前占位 0.60）。

> ⚠️ 说明口径：当前阈值是占位值 `0.60`，**未知判断的最终阈值须在未知样本补齐后用 `tools/calibrate.py` 校准**。演示时据实说明，不把占位值说成已校准结论。

---

## 5. 语音说出物体名称（必做项；模块已实现，界面尚未接线）

> ⚠️ 现状：`voice/asr.py` 已实现百度短语音识别并有单测，但 `app.py` **还没有语音按钮**（P3 未接线）。因此"在界面里说名称"当前无法演示，验收前若未接线就如实说明，不伪造。

- 可验证的部分：用脚本直接调用 `asr(<音频路径>)`，确认返回识别文本；确认 `.env` 已填 `BAIDU_ASR_API_KEY` / `BAIDU_ASR_SECRET_KEY`。
- 预期（接线后）：语音被识别为文本并填入名称框 / 作为检索关键词。
- 预期（当前）：命令行/脚本可跑通 `asr()`；界面仍用键盘录入。

坑：
- 缺 Key → `asr()` 抛 `AsrNotConfigured`（可捕获，不崩溃），不要当成程序错误。
- 网络不通 → 百度接口报错，异常只带错误码，不崩溃。
- 界面"语音入口置灰"是**待实现的预留行为**，当前没有该按钮，不要描述成已验证。

## 7. 查看特征库 / 重启后特征库仍在（必做项）

- Tab1 点「刷新特征库」：从磁盘重新读取 `data/features.json`，表格不变 → 说明内存与磁盘一致。
- **退出 `python app.py`，重新启动**，再次打开 Tab1：物体与向量条数仍在。
- 预期：重启后特征库不丢，无需重新录入。

坑：若重启后为空 → 检查上一步是否点了「录入并保存」（只录入不保存不会落盘）。
